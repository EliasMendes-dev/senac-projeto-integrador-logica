# Banco de Dados — Resumo para Decorar

## Dados
**Dados → Informação → Conhecimento**

- **Dados:** fatos/símbolos brutos, sem contexto.
- **Informação:** dados com **contexto e significado**.
- **Conhecimento:** **compreensão e uso** da informação para tomar decisões.

## Algoritmo
**Instruções → sequência → início, meio e fim**

- Conjunto **finito e ordenado de instruções** para resolver um problema ou realizar uma tarefa.

## Sistema de Informação (SI)
**Coleta → Processa → Armazena → Distribui → Apoia decisões**

- Conjunto de componentes que **coletam, processam, armazenam e distribuem informações** para apoiar decisões, coordenação e controle.

## SGBD
**Gerencia → Acessa → Organiza → Protege**

- Software responsável por **gerenciar um banco de dados**.
- Exemplos: **MySQL, PostgreSQL, Oracle, SQL Server**.

## Banco de Dados (BD)
**Dados organizados → relacionados → armazenados**

- Coleção organizada e estruturada de **dados relacionados**.

## Modelo Relacional
**Tabelas → Linhas → Colunas → Chaves**

- Organiza dados em **tabelas**, formadas por linhas e colunas.
- Exemplos: **MySQL e PostgreSQL**.

## Chaves
**PK = identifica | FK = relaciona**

- **PK (Chave Primária):** identifica unicamente um registro.
- **FK (Chave Estrangeira):** cria uma relação com outra tabela.

## Projeto de Banco de Dados
**Requisitos → Conceitual → Lógico → Físico**

- **Requisitos:** entender o que o sistema precisa.
- **Conceitual:** entidades e relacionamentos.
- **Lógico:** atributos e chaves.
- **Físico:** tabelas, colunas, tipos de dados e SQL.
