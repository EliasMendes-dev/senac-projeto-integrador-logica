# Evolução do programa Java — Aula 01 → Aula 02

> **Objetivo:** entender o programa passo a passo até conseguir escrever uma estrutura semelhante no papel, sem depender de copiar código.

---

## 1. Hello World básico

Primeiro, o programa mais simples possível:

```java
public class Aula01 {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

### O que memorizar

```text
public class NomeDaClasse
        ↓
    main()
        ↓
System.out.println()
```

### Estrutura

```java
public class Aula01 {

    public static void main(String[] args) {

        // código aqui

    }
}
```

- `class` → cria uma classe.
- `main` → ponto de entrada do programa.
- `System.out.println()` → mostra algo no console.
- `;` → termina uma instrução.

---

# 2. Entendendo o `main`

```java
public static void main(String[] args)
```

Não é necessário decorar cada palavra imediatamente, mas saiba identificar:

| Parte | Significado |
|---|---|
| `public` | acesso público |
| `static` | pertence à classe |
| `void` | não retorna valor |
| `main` | método inicial do programa |
| `String[] args` | argumentos recebidos pelo programa |

Para escrever no papel, o mais importante inicialmente é lembrar da estrutura:

```java
public static void main(String[] args) {

}
```

---

# 3. Adicionando entrada de dados com Scanner

Agora queremos que o usuário digite alguma coisa.

Primeiro precisamos importar o `Scanner`:

```java
import java.util.Scanner;
```

Depois criamos o Scanner:

```java
Scanner scanner = new Scanner(System.in);
```

### Programa

```java
import java.util.Scanner;

public class Aula01 {
    public static void main(String[] args) {

        Scanner scanner = new Scanner(System.in);

        System.out.println("Qual é seu nome?");
        String nome = scanner.nextLine();

        System.out.println("Olá " + nome);

        scanner.close();
    }
}
```

---

## 4. O que está acontecendo com o Scanner?

### Import

```java
import java.util.Scanner;
```

Estamos dizendo ao Java:

> "Quero utilizar a classe Scanner."

### Criação

```java
Scanner scanner = new Scanner(System.in);
```

Pense:

```text
Scanner
   ↓
tipo

scanner
   ↓
nome da variável

new Scanner(System.in)
   ↓
cria o Scanner para entrada pelo teclado
```

### Leitura

```java
String nome = scanner.nextLine();
```

Fluxo:

```text
Usuário digita
      ↓
Scanner lê
      ↓
nextLine()
      ↓
String nome
```

---

# 5. Diferentes tipos de entrada

Para texto:

```java
String nome = scanner.nextLine();
```

Para inteiro:

```java
int idade = scanner.nextInt();
```

Para `double`:

```java
double salario = scanner.nextDouble();
```

### Regra para memorizar

```text
nextLine()   → String
nextInt()    → int
nextDouble() → double
```

```java
System.out.println("Informe o primeiro numero:");
```

O fluxo é:

```text
   ↓

   ↓
```

# 7. Criando um método para soma

Em vez de fazer:

```java
int resultado = numero1 + numero2;
```

diretamente no `main`, podemos criar um método.

```java
public static int soma(int numero1, int numero2) {
    return numero1 + numero2;
}
```

### Entendendo a estrutura

```java
public static int soma(int numero1, int numero2)
```

| Parte | Função |
|---|---|
| `public` | acesso público |
| `static` | pode ser chamado pelo `main` |
| `int` | tipo que o método retorna |
| `soma` | nome do método |
| `int numero1` | primeiro parâmetro |
| `int numero2` | segundo parâmetro |

E:

```java
return numero1 + numero2;
```

significa:

> "Retorne o resultado dessa soma."

---

# 8. Chamando o método

No `main`:

```java
int resultado = soma(numero1, numero2);
```

Imagine:

```text
numero1 = 5
numero2 = 3

       ↓

soma(5, 3)

       ↓

5 + 3

       ↓

return 8

       ↓

resultado = 8
```

Depois:

```java
System.out.println("Resultado: " + resultado);
```

# 9. Adicionando horário

Agora queremos saber se é:

- Bom dia
- Boa tarde
- Boa noite

Para isso usamos `LocalTime`.

Import:

```java
import java.time.LocalTime;
```

Pegando o horário atual:

```java
LocalTime agora = LocalTime.now();
```

Pegando somente a hora:

```java
int hora = agora.getHour();
```

---

# 10. Usando `if` com a hora

Criamos uma variável:

```java
String data;
```

Depois:

```java
if (hora < 12) {
    data = "Bom dia!";
} else if (hora < 18) {
    data = "Boa tarde!";
} else {
    data = "Boa noite!";
}
```

### Pense assim:

```text
hora < 12
   ↓
Bom dia

hora < 18
   ↓
Boa tarde

caso contrário
   ↓
Boa noite
```

### Importante

Não fazemos:

```java
if (...) {
    String data = "Bom dia!";
}
```

porque essa variável ficaria limitada ao `if`.

Fazemos:

```java
String data;

if (...) {
    data = "Bom dia!";
}
```

Assim `data` pode ser utilizada depois:

```java
System.out.println("Olá " + nome + ", " + data);
```

```text
     ↓

     ↓

```

# 12. Programa completo

Chegamos finalmente ao programa:

```java
/* 19-08-2026 */

import java.time.LocalTime;
import java.util.Scanner;

public class Aula02 {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.println("Qual é seu nome?");
        String nome = scanner.nextLine();

        LocalTime agora = LocalTime.now();
        int hora = agora.getHour();
        String data;

        if (hora < 12) {
            data = "Bom dia!";
        } else if (hora < 18) {
            data = "Boa tarde!";
        } else {
            data = "Boa noite!";
        }

        System.out.println("Olá " + nome + ", " + data);

        System.out.println("Informe o primeiro numero:");
        int numero1 = scanner.nextInt();

        System.out.println("Informe o segundo numero:");
        int numero2 = scanner.nextInt();

        scanner.close();

        int resultado = soma(numero1, numero2);

        System.out.println("Resultado: " + resultado);
    }

    public static int soma(int numero1, int numero2) {
        return numero1 + numero2;
    }
}
```

# 🧠 Como pensar para escrever no papel

Em vez de tentar decorar o programa inteiro, memorize a **ordem de construção**:

```text
1. Classe
   ↓
2. main
   ↓
3. Scanner
   ↓
4. Entrada de dados
   ↓
5. Processamento
   ↓
6. if/else
   ↓
7. Método
   ↓
8. Resultado
```

Na prática, você pode pensar:

### ① Preciso criar a classe

```java
public class Aula02 {

}
```

### ② Preciso do `main`

```java
public static void main(String[] args) {

}
```

### ③ Preciso ler dados?

Então:

```java
import java.util.Scanner;
```

e:

```java
Scanner scanner = new Scanner(System.in);
```

### ④ Preciso de texto?

```java
String nome = scanner.nextLine();
```

### ⑤ Preciso de inteiro?

```java
int numero = scanner.nextInt();
```

### ⑥ Preciso tomar uma decisão?

```java
if (condicao) {

} else {

}
```

### ⑦ Preciso repetir uma operação?

Crio um método:

```java
public static int soma(int a, int b) {
    return a + b;
}
```

### ⑧ Preciso usar o resultado?

```java
int resultado = soma(a, b);
```

# 🎯 Objetivo do estudo

O objetivo não é lembrar **cada caractere**.

É conseguir reconstruir a lógica:

```text
IMPORTA O QUE PRECISA
        ↓
CRIA A CLASSE
        ↓
CRIA O MAIN
        ↓
DECLARA VARIÁVEIS
        ↓
RECEBE DADOS
        ↓
PROCESSA
        ↓
USA IF/ELSE
        ↓
CHAMA MÉTODOS
        ↓
MOSTRA RESULTADO
```

O objetivo é sair de:

> "Eu reconheço esse código."

para:

> "Eu consigo escrever esse código."
