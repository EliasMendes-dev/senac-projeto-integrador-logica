## 🎯 Sobre o Projeto

Este repositório reúne **exercícios práticos de lógica de programação** e outras disciplinas fundamentais para o curso de ADS. Os materiais incluem:

- ✅ Exemplos de código comentados

**Objetivo:** Desenvolver e praticar conceitos essenciais de **programação, lógica, estrutura de dados, banco de dados** e outras competências fundamentais para um desenvolvedor.

## 🚀 Como Usar

### 1. Clonar o Repositório
```bash
git clone https://github.com/EliasMendes-dev/senac-projeto-integrador-logica.git
cd senac-projeto-integrador-logica
```

### 2. Explorar os Exercícios
Navegue pelas pastas conforme seu interesse:
- Para aprender **Java básico**: vá para `Faculdade/Algoritmo e Programação/`
- Para estudar **algoritmos em pseudocódigo**: vá para `Faculdade/Projeto Integrador/13-08-2026 Semi-Portugol/`
- Para visualizar **fluxogramas**: vá para `Faculdade/Projeto Integrador/20-08-2026 Fluxograma/`

### 3. Compilar e Executar Códigos Java
```bash
javac Faculdade/Algoritmo\ e\ Programação/12-08-2026\ HelloWorld/Aula01.java
java -cp Faculdade/Algoritmo\ e\ Programação/12-08-2026\ HelloWorld Aula01
```
